05 — Questions

Before you ask

Do I need a build step or a framework? +

No. The kit is a single HTML file. Open it in a browser and it works — Tailwind loads from CDN, all interactions are vanilla JavaScript. Drop it into any static host.

Can I change the accent colour and the dark theme? +

Yes — both are one attribute on the <html> tag: data-theme="dark|light" and data-accent="coral|butter|mint|sky|violet". The playground above previews every combination live.

Are the charts real or images? +

Real. Bars, sparklines, rings and funnels are inline SVG drawn from data in the file. Hover any of them for exact values — and swap the data arrays to make them yours.

Does it work on mobile? +

Yes. Below 900 px every bento recomposes into a single-column stack, the top navigation becomes a bottom tab bar, and touch targets stay above 44 px.

What do I get when I buy? +

The full source (index.html), a README with the token reference and layout guide, and free updates for life. Delivered as a .zip through 21st.dev.
